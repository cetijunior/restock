# Furnizim · Market Lami

Restock app for Market Lami: pick products, set quantities, and send the order to a supplier by WhatsApp, PDF or text.

- 323-product catalogue with categories, accent-insensitive search (`/` to focus), sorting, margin badges
- Product images (Open Food Facts links) where an exact match exists, emoji icons otherwise
- Add / edit / delete products; list, supplier and note persist on the device
- Order history with repeat, re-share and 30-day spend
- JSON backup / import, installable PWA, works offline

Stack: Vite · React 19 · TypeScript · Tailwind 4 · Zustand · jsPDF (lazy-loaded)

```bash
npm i && npm run dev
```
